`Node.js` `Express.js` `MongoDB` `JWT` `JavaScript`
&nbsp;&nbsp;[🔗 Live Demo](https://ledger-booking.netlify.app)

---

### 📚 [LearnFlow — E-Learning Platform](https://github.com/Anushri488/learnflow)
Full-stack e-learning platform spanning 6 courses, 30+ lessons, and 12 quizzes, with a gamified XP system and progress tracking synced to MongoDB across devices.

`Node.js` `Express.js` `MongoDB` `JWT` `JavaScript`
&nbsp;&nbsp;[🔗 Live Demo](https://anushri488.github.io/learnflow)

`Python` `Scikit-learn` `Flask` `React` `Pandas` `ML`
